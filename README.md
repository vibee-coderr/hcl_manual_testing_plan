# Flipkart Shopping Application – Manual Testing

## 📌 Project Overview

This project contains a **Manual Functional Testing Plan** for the Flipkart Shopping Application.

The test plan focuses on validating the **end-to-end purchase flow**, starting from user login and product search and continuing through cart, delivery address, payment selection, and order confirmation.

## 🎯 Test Objective

To ensure that a user can successfully:

- Log in to the application
- Search for a product
- View product details
- Add a product to the cart
- Review the cart
- Select a delivery address
- Review the order summary
- Select a payment method
- Successfully place an order
